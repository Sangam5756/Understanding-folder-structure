# Understanding Folder Structure

This repository is part of my backend development learning journey. It focuses on understanding and organizing folder structures in backend projects.

## 📁 Project Structure

- `src/` – Contains the source code files.
- `package.json` – Lists project dependencies and scripts.
- `.gitignore` – Specifies files and directories to be ignored by Git.
- `README.md` – Provides information about the project.

## 🧠 Purpose

To learn and implement best practices for structuring backend projects, enhancing code maintainability and scalability.

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Sangam5756/Understanding-folder-structure.git
````

2. Navigate to the project directory:

   ```bash
   cd Understanding-folder-structure
   ```
3. Install dependencies:

   ```bash
   npm install
   ```
4. Start the development server:

   ```bash
   npm start
   ```
